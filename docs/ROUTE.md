# Маршруты: `cii route`

Модуль показывает, как трафик доходит до крупных сетей: напрямую, через пиринг, через транзит или с крюком. Идея и пороги — из [remnawave/geocheck](https://github.com/remnawave/geocheck), реализация своя.

```
cii route              # только маршруты
cii route --tcp        # без ICMP: только время TCP-соединения
cii --route            # маршруты вместе с основным отчётом
```

Флаги: `--tcp` — не трассировать ICMP; `--rounds N` — число раундов ICMP (1–15, по умолчанию 3); `--max-hops N` — максимум хопов (1–31, по умолчанию 24). Работают общие флаги `-4`/`-6`, `--iface`, `--source`, `--timeout`, `--json`, `--debug`, `--mask`, `--plan`, `--svg`.

| Messaging | Telegram DC2 и DC4 (AS62041), Discord (AS13335) |

Все хосты объявлены в политике модуля `route` (`cii route --plan`). Имена разрешаются системным резолвером через netx.

## Как измеряется

**ICMP.** Если есть права на сырой сокет (root или `CAP_NET_RAW`, только IPv4), cii отправляет эхо-запросы сразу со всеми TTL от 1 до `--max-hops` ко всем целям, несколько раундов. Ответы «TTL exceeded» дают хопы, эхо-ответ — расстояние до цели. Для каждого хопа берётся минимальное время по раундам. Отправка к цели прекращается на TTL, на котором она ответила.

**TCP.** Цели, которые не ответили на ICMP (многие CDN молчат), и все цели без прав на сырой сокет или по IPv6 замеряются временем TCP-соединения с портом 443: четыре попытки с паузой 50 мс, берётся минимум. Хопов в этом случае нет.

ASN хопов и цели берутся из локальной базы DB-IP ASN Lite (`cii data update`). В сеть за этим cii не ходит. Без базы хопы не подписаны, и транзит не определяется. Собственная AS берётся из основного отчёта, а в `cii route` — из первого публичного хопа.

При прокси (`--proxy` или переменные окружения) ICMP и TCP-замеры не выполняются: они ушли бы мимо прокси.

## Вердикты

«Быстрейший путь» — минимальная задержка среди целей, а если ответили четыре и больше — вторая по скорости, чтобы один выброс не сдвигал шкалу. Превышение считается от неё.

| Вердикт | Значок | Условие |
|---|---|---|
| `direct` | ✓ | превышение не больше 5 мс |
| `near` | ✓ | превышение до 25 мс |
| `distant` | ✓ | цель с одной площадкой (Telegram DC, GitHub) дальше 25 мс: это расстояние, а не проблема маршрута. Для таких целей вердикты `regional` и `detour` не выносятся, скачки задержки не учитываются |
| `regional` | ◐ | превышение до 60 мс |
| `transit` | ◐ | на пути до сети цели есть транзитная AS из списка (Cogent, Arelion, Lumen, GTT, NTT, Tata, Hurricane Electric, RETN, TransTelecom и др.), не ваша и не сеть цели |
| `detour` | ✗ | превышение больше 60 мс или один участок пути добавляет больше 40 мс |
| `intercepted` | ✗ | ICMP-ответ быстрее 1 мс без промежуточных хопов; или шесть и больше целей из четырёх и больше разных сетей ответили быстрее 2 мс, и при этом трассировка не показала настоящих хопов (три и больше разных адресов на пути) — тогда соединения завершает локальный прокси, туннель или песочница. В хорошо связанном дата-центре все CDN отвечают за 1 мс, но хопы видны, и это правило не срабатывает |
| `unreachable` | ! | ни ICMP, ни TCP не дали ответа |

**Задержки хопов.** Роутеры отвечают на истёкший TTL медленнее, чем пересылают трафик, и ограничивают частоту таких ответов. Поэтому хоп может показать 20 мс, а следующий за ним — 1 мс. Чтобы это не выглядело крюком, скачок считается по «эффективной» задержке: для каждого хопа берётся минимум из его времени и времени всех следующих хопов и самой цели. Пакеты отправляются с паузой 0,2 мс и в разном порядке целей в каждом раунде, чтобы один роутер не получал пачку сразу и не задерживал ответы.

Если ответ пришёл из другой AS, чем ожидается (например, Google из кэша у провайдера), в пояснении пишется «served from ASn …». Если эта AS — ваша собственная, пишется «served from a cache inside your network»: это хороший признак, а не проблема.

`--debug` печатает по каждой цели адрес, AS, способ замера и список хопов с задержками и AS. В JSON — объект `route` с полями `method`, `floor_ms`, `own_asn`, `note` и `paths[]` (`target`, `addr`, `asn`, `org`, `rtt_ms`, `timing`, `hops[]`, `transit[]`, `jump_ms`, `verdict`, `reason`). С `--mask` адреса хопов и цели, номера AS и названия организаций скрываются.
