# Разбор проектов-примеров

Снимок на ноябрь 2026. Код этих проектов в cii **не вызывается и не скачивается**. Берутся идеи, логика проверок и форматы, переписанные на Go; при прямом переносе фрагментов — с сохранением авторства (см. [CREDITS.md](../CREDITS.md)).

## lmc999/RegionRestrictionCheck — AGPL-3.0

| Находка | Где | Решение в cii |
|---|---|---|
| Счётчик запусков на `*.workers.dev` | `check.sh:476` | не переносится |
| `cookies` и IATA-справочники скачиваются с GitHub при каждом запуске | `check.sh:482-484` | справочники встраиваются, cookies с токенами не используются |
| Рекламные скрипты через `bash <(curl …)` | `check.sh:5959-5981` | не переносится |
| Скачивается и запускается закрытый бинарник `ins` | `check.sh:3683` | не переносится |
| shc-обфусцированные `binary/Hulu*.sh.x` | `binary/` | не используются |
| Логин и пароль чужого аккаунта Hulu | `check.sh:1429` | уровень C, исключено |
| ~140 функций проверок по регионам | весь файл | основной источник каталога `services` (уровни A/B) |

## itdoginfo/russian-iperf3-servers — лицензии нет

В репозитории нет лицензии, поэтому код и список не копируются. Список iperf3-серверов в cii собирается самостоятельно, по публичным данным операторов; список itdoginfo служит подсказкой, где искать.
