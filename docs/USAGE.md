# Использование

[English version](en/USAGE.md)

## Меню

`cii` без параметров в терминале показывает режимы и ждёт номер:

```
   1  Обычная проверка          адрес, качество IP, регион, сервисы, репутация, цензура
   2  Расширенная проверка      обычная + внутренние API сервисов, страницы риска, списки DPI и геоблокировок
   3  Всё сразу                 расширенная + маршруты + бенчмарк (минуты, 1 ГиБ на диске)
   4  Быстро                    только адрес и локальные базы
   5  Только цензура            DNS, DPI, геоблокировки, Telegram, проверки связи
   6  Только маршруты           пути к крупным сетям (для хопов нужен root)
   7  Только бенчмарк           система, диск, CPU, скорость, iperf3
   8  Показать прошлый запуск   из локального лога, без сети
   9  Разобрать прошлый запуск  выводы по локальному логу, без сети
  10  Обновить базы             DB-IP Lite и списки диапазонов у издателей
```

Буква `m` после номера (`2m`) скрывает адреса и провайдера. Enter без номера запускает обычную проверку, `0` — выход. Номер можно дать сразу параметром: `cii 2m`. `cii ip` запускает обычную проверку без меню. Когда ввод или вывод не терминал (скрипт, конвейер), меню нет и идёт обычная проверка. В терминале уже примерно 100 колонок меню показывается без пояснений, одними названиями.

## Команды

| Команда | Что делает |
|---|---|
| `cii` | полная проверка: адрес, качество IP, регион, сервисы, репутация, цензура (DNS, Telegram, проверки связи) |
| `cii lookup IP…` | описать указанные адреса по локальным базам, без сети |
| `cii censor` | только цензура, все режимы и полная сетка ([CENSOR_CHECKS.md](CENSOR_CHECKS.md)) |
| `cii route` | только маршруты; `--targets` задаёт свои цели, `-6` трассирует по IPv6 ([ROUTE.md](ROUTE.md)) |
| `cii bench` | только бенчмарк, со своими настройками ([BENCH.md](BENCH.md)) |
| `cii show [ЛОГ\|JSON\|-]` | показать прошлый запуск заново: без аргумента — последний локальный лог, можно файл лога, JSON от `--json` или `-` (стандартный ввод). Работают `--mask`, `--json`, `--debug`, `--svg`, `--lang`; в заголовке видно, из какого файла отчёт и когда он снят |
| `cii analyze [ЛОГ\|JSON\|-]` | выводы по готовому запуску, ничего не проверяя заново: перехват DNS и что из него следует, выход DNS в другой стране (утечка), блокировки, изменённый HTTP или TLS, туннель, тип адреса и флаги риска, чёрные списки, крюки маршрутов. По умолчанию — последний лог; работают `--mask`, `--json`, `--lang`. Сам отчёт `cii` остаётся как есть, без толкований |
| `cii stats [ЛОГ…]` | какие проверки отвечали не всегда, по всем локальным логам: так видно проверку, которая сломалась из-за изменений на стороне сервиса |
| `cii diff [OLD NEW]` | что изменилось между двумя запусками; без аргументов — два последних лога |
| `cii compare A B [C…]` | отчёты с разных машин рядом (от двух до шести логов или JSON): панель качества IP на каждую точку и общая сетка сервисов с отметкой по каждой; для двух точек ниже печатается список различий. Работают `--mask`, `--json`, `--svg` |
| `cii watch` | повторять проверку каждые `--every` (по умолчанию 30 минут, не чаще 5) и печатать, что изменилось: адрес, вердикт, доступность сервисов, блокировки, оценки. Первый запуск показывает полный отчёт. `--count N` останавливает после N запусков, `--prom-file` обновляет файл метрик. Принимает флаги `cii` (`--extended`, `--route`, `--mask`…); с `--mask` смена адреса не видна |
| `cii data update [ID…]` | скачать офлайн-базы у издателей; `status` — что скачано, `sources` — какие есть |
| `cii completion SHELL` | скрипт автодополнения для `bash`, `zsh` или `fish` (см. [INSTALL.md](INSTALL.md)) |
| `cii man` | справка в виде страницы man |
| `cii version` | версия |

## Флаги

| Флаг | Что значит |
|---|---|
| `--extended` | ещё проверки уровня B: внутренние API сервисов, страницы проверки адреса у сервисов риска, списки DPI и геоблокировок |
| `--route` | добавить анализ маршрутов |
| `--bench` | добавить бенчмарк (минуты, 1 ГиБ на диске, трафик iperf3) |
| `--quick` | только адрес и локальные базы, без проверок сервисов |
| `--no-censor`, `--no-risk` | без цензуры; без репутации, DNSBL и почты |
| `-4`, `-6` | только IPv4 или только IPv6 |
| `--proxy URL[,URL…]` | проверять через прокси (`http://`, `https://`, `socks5://`); несколько адресов — несколько выходов рядом |
| `--iface NAME`, `--source ADDR` | выходить через указанный интерфейс или адрес |
| `--catalog LIST` | региональные каталоги сервисов: `auto` (по стране), `all`, `none` или коды вроде `JP,EU` |
| `--timeout DUR` | тайм-аут одного запроса, по умолчанию `10s` |
| `--offline` | не ходить в сеть: адреса с интерфейсов и локальные базы |
| `--plan` | напечатать все адреса, к которым cii может обратиться, и выйти |
| `--json` | машиночитаемый вывод по схеме [`schema/report.schema.json`](../schema/report.schema.json) |
| `--debug` | полные таблицы, причины ошибок и журнал всех соединений |
| `--mask` | скрыть адреса, подсети, номера и владельцев AS, PTR — для скриншотов |
| `--svg FILE` | сохранить итоговый экран картинкой SVG |
| `--html FILE` | сохранить итоговый экран страницей HTML: один файл без скриптов и внешних ресурсов, текст можно выделять и копировать |
| `--prom`, `--prom-file FILE` | вывести отчёт метриками Prometheus вместо экрана; записать их в файл (например, для textfile-коллектора node_exporter) |
| `--demo` | показать отчёт на выдуманных данных, без сети |
| `--lang auto\|en\|ru` | язык экрана; `--debug` и JSON всегда на английском |
| `--no-color`, `--no-log` | без цвета; без локального лога |
| `--config FILE`, `--data-dir DIR` | свой конфиг (ключи, свой echo-сервис) и каталог баз |

Свои ключи (ipinfo, IPQS, AbuseIPDB, Gemini и др.) включают дополнительные проверки — см. [CONFIG.md](CONFIG.md). Без них всё работает.

## Экран

Раскладка зависит от ширины окна: до 110 символов — одна колонка, от 110 — две, от 200 — три. Рассчитана на терминалы от 50 колонок и 24 строк (окно 500×500 или 640×480): таблицы сужаются, длинные строки переносятся. Во время работы экран обновляется на месте, `◌` — проверка ещё идёт. Если кадр выше окна, внизу пишется, сколько строк скрыто, а полный отчёт печатается по завершении. Ctrl+C показывает то, что успело прийти.

Отметки: `✓` да, `✗` нет, `◐` частично, `⊘` адрес заблокирован сервисом, `?` нет ответа, `!` ошибка, `*` проверка уровня `--extended`.

## Лог и `--mask`

Каждый запуск сохраняет кадр, подробный отчёт и JSON в локальный лог: `~/.local/state/cii/logs` на Linux, `~/Library/Logs/cii` на macOS, `%LOCALAPPDATA%\cii\logs` на Windows. Права — 0600, хранятся последние 20 запусков, никуда не отправляется. По логам работают `cii show`, `cii analyze`, `cii stats` и `cii diff`.

`--mask` заменяет на `•••` всё, по чему можно узнать адрес или сеть: адреса и подсети в любом виде, номера и владельцев AS, PTR, адреса хопов, имена узлов CDN, названия VPN, дата-центров и транзитных сетей, хосты своих целей маршрутов и своих проверок сервисов. Страна, город и все результаты проверок остаются. `cii show --mask` маскирует и прошлый запуск, который шёл без `--mask`.
