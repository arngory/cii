# Офлайн-данные

| ID | Что | Лицензия | Ключ | Можно класть в релизы |
|---|---|---|---|---|
| `dbip-country-lite` | DB-IP IP to Country Lite | CC BY 4.0 | нет | да |
| `dbip-asn-lite` | DB-IP IP to ASN Lite | CC BY 4.0 | нет | да |
| `dbip-city-lite` | DB-IP IP to City Lite (~130 МБ) | CC BY 4.0 | нет | да |
| `ipinfo-lite` | IPinfo Lite (страна + ASN) | CC BY-SA 4.0 | `ipinfo_token` | да, с атрибуцией |
| `geolite2-country`, `geolite2-city`, `geolite2-asn` | MaxMind GeoLite2 | GeoLite2 EULA | `maxmind_account_id` + `maxmind_license_key` | **нет** |

Как устроена загрузка:

- Загрузка только явная: `cii data update [ID...]`. Обращение идёт только к хостам издателя (их показывает `cii data update --plan`).
- DB-IP выкладывает базы помесячно. Если файла текущего месяца ещё нет, берётся предыдущий месяц.
- Скачанный файл проверяется как корректная MaxMind DB и только потом атомарно заменяет старый.
- В `manifest.json` записываются URL без секретов, дата загрузки, дата сборки базы, тип, размер и sha256.

Строки атрибуции, которых требуют лицензии, cii выводит в каждом отчёте, где использовалась соответствующая база.

## Будущие наборы (для модуля `risk`)

Официальные диапазоны AWS, GCP, Azure, Oracle, Cloudflare и DigitalOcean, список выходных узлов Tor, выборочные списки FireHOL (лицензия проверяется по каждому). Принцип тот же: только первоисточник, только явное обновление, sha256 в манифесте.

## Релизные снимки

Release-workflow может приложить к релизу снимки баз `*.mmdb.gz`: DB-IP Lite всегда, IPinfo Lite — если в репозитории задан секрет `IPINFO_TOKEN`. cii сам эти файлы не скачивает: их распаковывают вручную, если нужно работать вообще без обращений к издателям.
